# E-Commerce Data Analysis Using SQL

## Overview
This project demonstrates SQL-based data analysis on an E-Commerce database. The database contains six tables: Customers, Products, Orders, Payments, Suppliers, and Reviews.

## SQL Operations Performed
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- Subqueries
- Aggregate Functions (SUM, AVG)
- Views
- Indexes

## Database Tables
1. Customers
2. Products
3. Orders
4. Payments
5. Suppliers
6. Reviews

## Key Analysis
- Customer spending analysis
- Product performance analysis
- Revenue calculation
- Average order value
- Payment method analysis
- Customer review analysis

## Technologies Used
- MySQL
- SQL
- MySQL Command Line Client

## Learning Outcomes
- Database creation and management
- Data querying and filtering
- SQL joins and subqueries
- Data aggregation and analysis
- Query optimization using indexes
